# Project status

## Complete in this package

- Rebuilt FE-2PEF forward model based on two modulated lasers and three excitation pathways.
- Analytic and direct time-domain lock-in implementations.
- Single-detector noise model and detector-bandwidth response.
- Calibrated NNLS and regularized blind NNMF.
- Conventional emission-filtered comparator.
- 2-D RPE-like, overlap, two-spot, and small 3-D phantoms.
- Nine robustness sweeps with replicate-level CSV output.
- Tests, example outputs, manuscript templates, and detailed function docstrings.

## Not complete scientifically

- Measured A2E/FAD/non-A2E-lipofuscin two-photon pathway responses.
- Measured emission/filter matrix and detector transfer function.
- Ocular aberration and tissue-scattering validation.
- Phantom, cell, ex-vivo, or in-vivo validation.
- Qualified ocular-safety assessment.

## Best current claim

This is a reproducible computational framework for evaluating when frequency-encoded 2PEF may improve retinal fluorophore unmixing. It is not yet evidence of clinical performance.
