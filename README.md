# Final FE-TPEF branch #

This repository contains all the code which we used to conduct a simulation on Frequency Encoded- Two-Photon Excitation Fluorescence on the retina.

Each of the stages of the model have been split into different files, and to conduct the simulation, run
```
py run_comparison.py
```
when your file path is set to your project directory.

The aim of the simulation is to essentially show that there is an improvement in image quality when conducting TPEF along with Frequency Encoding.
